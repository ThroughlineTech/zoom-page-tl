# Zoom Page WE — Zoom Level Investigation Tickets

> Each ticket asks a developer to investigate whether the specific zoom-level value is a
> useful option to offer in this app. Deliverable per ticket: a short summary report in
> the ticket body covering real-world usage, value to users, and a keep/remove recommendation.
