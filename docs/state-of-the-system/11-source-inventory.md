## Where to look for a change

- Zoom not applying, wrong level, flicker: `content.js` `refresh`/`apply`/re-assert, then `core.spec.js`.
- Native bubble or badge: `background.js` `applyZoomMode`/`refreshBadge`.
- Fit result wrong on a site: `content.js` `pickContentTargets`/`computeAutofitFactor`; reproduce with `npm run shot`, reduce to a `tests/server.js` route.
- Content sliding sideways: `content.js` `applyRecenter`; `/drift` fixture.
- Popup control behavior: `popup.js`; options list or backup: `options.js` and `options.spec.js`.
- Keyboard shortcuts: matching and rules in `zoom.js`, dispatch in `content.js` `runShortcut`, recording UI in `options.js`; `shortcuts.spec.js`.
- New storage key: update every reader listed in [07](07-public-surfaces-and-contracts.md), `removeSite`, and possibly the backup format.
